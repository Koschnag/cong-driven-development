# CDD Research Overview Video

Reproduzierbare 30-Sekunden-Projektion des Forschungsprogramms. Sie behauptet keine
empirischen Ergebnisse, sondern zeigt Kernmodell, epistemische Trennung, Teilprojekte
und die Rolle des menschlichen Reviews.

```bash
npm install
npm run lint
npm run poster
npm run render
```

Die Exporte liegen unter `docs/media/`. Bei einer wesentlichen Änderung an Claims oder
Systemgrenzen müssen Storyboard und Text erneut mit dem SPOT abgeglichen werden.
