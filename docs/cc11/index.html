01 / Position

The premise

Faster generation moves the bottleneck. It does not remove responsibility.

When software can be generated in minutes, the scarce work becomes intent, evidence, memory and permission. CC11 treats those as architecture—not prompt etiquette.

It combines a conservative record with an experimental EIDOS lane. Both may inform decisions. Only one may become ratified truth, and only through an explicit promotion gate.
