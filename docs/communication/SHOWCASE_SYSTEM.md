# Showcase system

Die Showcase-Seite ist eine statische, read-only Projektion des öffentlichen
SPOT-Snapshots. Sie enthält keinen Steuerkanal und kann keine Arbeit starten,
akzeptieren oder promoten. Die lokale Reproduktion erfolgt mit
`scripts/build-pages.sh`; der Pages-Workflow bleibt deaktiviert.

Angezeigte Zahlen sind bis zu einem echten, redigierten Export `unknown`.
`main` bedeutet geprüfte Wahrheit, `live-wip` bedeutet Kontinuität ohne
Abnahme. Verweise auf Forschung sind direkte Primärquellen; die Seite macht
keinen Neuheits- oder Überlegenheitsanspruch.
