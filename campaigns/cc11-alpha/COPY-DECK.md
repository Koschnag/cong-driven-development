# CC11 Alpha copy deck

## Master copy

### Headline

A system that can show its work.

### Short descriptor

Private memory. Typed action. Evidence before authority.

### 50-word description

CC11 is the private memory and automation research release of CC10. It keeps
sources, claims, experiments and authority visibly separate. A conservative
Core records what may be trusted; an EIDOS lab explores candidates; evidence
and owner-controlled promotion decide what may cross the boundary.

### Honest status

CC11 currently runs as a private shadow alpha. It is not the default memory
system, not a public SaaS and not authorised to promote its own conclusions.

## Social launch sequence

### Post 1 — Position

AI can generate an answer.  
The harder question is what that answer is allowed to become.

CC11 is a private memory and automation research release built around one
boundary: memory is not authority.

Private shadow alpha. Public method. Inspectable limits.

### Post 2 — System

CC11 keeps six states visible:

Source → Claim → Candidate → Assurance → Promotion → Outcome

The generator does not get to call itself correct. Evidence travels with the
change; authority remains explicit.

### Post 3 — Research

The public work is Cong-Driven Development: paper, F# framework, CourseForge
reference project and CDD Studio.

The private CC10/CC11 system is the operational case study. Public releases are
sanitised projections, never exports of personal memory.

### Post 4 — Open work

What is still open in CC11:

- frozen retrieval evaluation;
- complete Matrix-to-action integration receipt;
- full durability and rollback gate;
- stable/default cutover.

Alpha means the limits are part of the release.

## Do not use

- “Your AI knows everything.”
- “Fully autonomous.”
- “Production-ready.”
- “Self-healing” or “self-improving” without the qualifying gate.
- “Zero trust” as a marketing adjective without a specific boundary.
- “European” as a proxy for secure, private or ethical.
- Any percentage, time saving or reliability number without a public protocol.
