# CC11 Alpha campaign

## Campaign idea

**A system that can show its work.**

CC11 is not marketed as a smarter chatbot or an autonomous employee. The
campaign presents it as a research release for accountable personal systems:
private memory, typed action and evidence before authority.

The public campaign is intentionally narrower than the private system. It
contains no personal documents, DWH excerpts, credentials, private routes,
operational addresses, customer claims or invented performance metrics.

## Audience

1. Software and platform engineers working with agentic systems.
2. Researchers interested in evidence-gated software evolution.
3. Technical decision-makers evaluating sovereign or private AI systems.
4. Builders who distrust both AI hype and purely defensive rejection.

## Position

| Conventional message | CC11 position |
|---|---|
| “AI that knows everything about you” | Memory remains source-bound and inspectable |
| “Autonomous agents” | Authority is typed, scoped and revocable |
| “Self-improving system” | Experiments remain candidates until evidence-gated promotion |
| “One intelligent brain” | Conservative Core and labelled EIDOS lab have different authority |
| “Production-ready” | Private shadow alpha with disclosed open gates |

## Creative rules

- Build the visual language from real system concepts: records, states, gates,
  receipts and boundaries.
- Use editorial typography, measured spacing and a fixed grid.
- Use vermilion only for authority, unresolved status and the core distinction.
- Use no generated people, fake screenshots, 3D blobs, glowing network spheres,
  glass cards, generic gradients or stock “future of AI” imagery.
- Use no fake customers, quotes, logos, adoption figures or productivity claims.
- Every release claim must be one of `Verified`, `Observed`, `Pending` or
  `Blocked`.
- Motion remains typographic and understandable without audio.
